Error Log

Win Probability
Each player's estimated chance to win, updated after every move. Computed by W, a deterministic model over public board features only — nothing it uses is hidden from the table. The current number also sits on each player's row in the Board tab.

Player Analytics
Decision quality is measured within each category only (e.g. "was this the best-scoring LEGAL road among road candidates"), not across categories. Luck and damage-from-others are reported separately, never blended into it.
